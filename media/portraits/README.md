# Living portraits (Harry Potter style)

Drop short clips here and the site auto-activates them — no code changes needed.

- Filenames: nick.mp4 · patrick.mp4 · lisset.mp4 · valen.mp4
- 0.5–2 seconds, MUTED audio track or none, shot steady (tripod) so the freeze-frame doesn't jump
- Square-ish crop looks best (they render in a circle), a few MB max each
- Behavior: portrait sits frozen; plays once on hover, and once when scrolled into view on mobile

Until a file exists, its portrait slot is invisible.
